# 简要需求 v0.2

> 当前实现说明（2026-11-05）：下文保留早期设计／计划，未实现条目不构成功能承诺。当前项目与任务由授权智能体创建，状态由本机独立确认；连接中心保存首次范围，创建项目默认关闭、待办单独授权，MCP 提供四工具。用户入口见[用户指南](user-guide.md)，精确能力与验证边界见[接入指南](agent-integration-guide.md)。QQ 与音频转写仍需后续验证／实现。


## 目标

提供轻量 macOS 工作进度台：菜单栏摘要、可置顶悬浮窗和按需打开的管理窗口。统一展示当前阶段、下一步、阻塞、来源与更新时间。

## 范围

P0：手动管理项目/阶段/待办；快捷录入；菜单栏与悬浮窗；SQLite 持久化；统一智能体事件接入；来源、去重、冲突提示。

P1：QQ 查询与录入；会议音频/文字转写与纪要；带时间戳依据的待办草稿，确认后入库；授权资料跳转；提醒降噪。

P2：更多智能体、周报、交接摘要、实验记录卡。按需选择，不默认增加常驻功能。

## 状态规则

会话运行状态与任务进度分开；运行结束不代表任务完成。AI 不猜测进度百分比。手动确认状态不被静默覆盖；不明确的负责人和日期留待确认。

## 权限

接口按来源和项目授权。QQ 不代替电脑端本地文件授权。QQ 定时任务使用指定独立工作区。其他人的工作空间默认不接入。

## 轻量预算（目标，非实测）

- 单常驻应用，无 Electron、内嵌浏览器、Python/Node 常驻后端或独立数据库服务。
- Release 包目标 <=30 MB（不含可选模型），空闲内存目标 <=100 MB，空闲平均 CPU 目标 <1%。
- 离线手动操作可用；UI 不因模型调用阻塞；无周期 LLM 调用。
- 优先在线转写作为候选默认，必须确认音频上传；本地模型单独下载，按需启动，任务后卸载。

验收采用同一台机器、Release、100 项目/1000 待办/10000 事件的合成数据，预热后观察 10 分钟；关闭模型和主动转写。记录物理内存、CPU、唤醒次数、包体、首屏和更新延迟。超预算先分析再调整，不宣称保证值。

## 待定

QQ 渠道实际能力；首个智能体接入机制；在线/本地转写选择。上面的功能范围为设计基线，尚待用户选择。
