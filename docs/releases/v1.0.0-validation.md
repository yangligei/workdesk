# Workdesk v1.0.0 验收

日期：2026-11-06。环境：macOS 27.0.1 / Apple Silicon，目标 macOS 13+ arm64。修复提交：b6d35fea02884516b1031ab3cc20020bc302a704。版本 1.0.0 / build 2。

## 结论与范围

下列必要功能验收通过，允许发布首个版本。所有写入测试使用隔离样例，不修改真实项目、事项、权限或密钥；未跟踪 artifacts 包含真实证据，不提交、不打包。仓库保持私有。源码上传不等于发布，应用 ZIP、校验和与离线 HTML 手册作为独立 release assets 交付。

## 发现与修复

- 发现空闲窗口仅在用户刷新时归档，超过 12 小时也不会自动更新。生产 Model 现在用一次性定时器安排最近归档期限，数据刷新后重排，系统唤醒时补扫；不会引入常驻服务。前次隔离回归明确失败，修复后本次再次通过。
- 旧 schema 迁移使用迁移时间保守起算；增加真实 SQLite 旧表迁移、精确 12 小时边界、完成后改名不重置时间、项目状态独立与归档计数测试。

## 明确限制

- 本机仅 Command Line Tools，XCTest 平台路径不可用；未声称 `swift test` 通过。可执行 CoreChecks 与生产原生隔离回归已运行。
- 未完成系统级 CG/HID 自动点击与实体触控板人工全流程；实际原生 widget / NSMenu / NSEvent 及离屏生产视图构成本次界面验收。
- 仅 arm64 包；未在 Intel 或 macOS 13 实机运行。macOS 13 是编译最低版本，不是本次实机环境。
- ad-hoc 签名，未经 Apple Developer ID 签名或公证；下载后可能遇到 Gatekeeper，需要用户自行确认来源并使用系统“仍要打开”。
- 自动归档仅在应用运行时定时执行；关闭期间到期的事项在下次启动补扫，睡眠期间在唤醒补扫。
- AI 识别依赖本机可用 Hermes 配置与网络；模型结果仍须人工审核确认。
- 未执行实体打印、整机长时间资源基准或真实用户数据写入回归。不将启动成功表述为所有交互人工验收。
