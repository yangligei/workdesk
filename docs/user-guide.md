# Workdesk 中文用户指南

图文阅读入口：[离线 HTML 用户手册](manual/workdesk-user-manual.html)（图片已内嵌，可单独发送和离线打开）。

一句话：Workdesk 把项目、任务、智能体进展和会议事项放在本机工作台中，让你查看下一步、确认状态并审核入库。

本指南依据当前版本界面与代码编写，适用于 macOS 13 及以上版本。

## 快速开始

1. 打开 `Workdesk.app`。从源码打包的应用位于仓库内的 `dist/Workdesk.app`。
2. 启动后会显示「今日进度」置顶窗，菜单栏出现清单图标。
3. 左键单击菜单栏图标，可再次打开置顶窗。
4. 在图标上右键，或用触控板双指按压，松手后打开菜单。
5. 选择「打开管理窗口…」，查看项目总览、项目待办和会议收件箱。
6. 首次使用先进入「设置与接入」，登记身份、接入项目，再让智能体上报事项。

**菜单手势是右键／双指按压；左键连续点两下仍是打开置顶窗。**

关闭窗口不会退出 Workdesk。要结束应用，请在菜单栏菜单中选择「退出 Workdesk」。

### 空白工作台如何开始

界面没有「新增项目」或「新增任务」按钮，新增事项交给已登记并获授权的智能体。

- 已有项目：在连接中心选择身份、项目并授权，再连接客户端。
- 一个项目也没有：在连接中心选择有效身份，勾选「允许创建新项目」，按需勾选「允许创建待办」，点击「授权所选范围并记住」，再连接客户端让智能体创建首个项目。
- 创建新项目默认关闭；本机授权后可通过 `workdesk_project_create` 创建。登记身份或配置连接本身不会自动授权。
- 普通用户日常查看、改状态、审核会议不需要编写代码；首次空工作台接入仍需要上述本机管理步骤。

## 常用操作

### 在置顶窗查看今天的工作

顶部是一排项目标签。点击项目名切换；项目较多时可横向滚动，也可点左右箭头滚动标签，再选择项目。

每个项目显示名称、阶段、独立的项目状态、当前任务完成数，以及「最近进展」。

- 点击「更早进展」整行，展开或收起历史进展。
- 进展下方显示来源与来源时间，方便核对是谁上报、何时发生。
- 「暂无已接受的进展」表示当前项目还没有可展示的已接受上报。
- 「暂无任务」时，可让已接入智能体新增待办。

项目标签只负责切换视图，不会改变项目或任务状态。

### 修改状态

点击项目右侧「项目状态」按钮，或某条任务右侧的状态按钮，选择新状态即可保存。
按钮包含文字、图标和箭头，整个区域可点，尺寸为 152 × 48 点。

| 状态 | 颜色 | 建议用法 |
| --- | --- | --- |
| 待办 | 灰色 | 已记录，尚未开始 |
| 进行中 | 蓝色 | 正在推进 |
| 等待汇报/反馈 | 紫色 | 已做完当前动作，等待汇报、回复或确认 |
| 阻塞 | 橙红色 | 有问题阻止继续，需要处理 |
| 完成 | 绿色 | 你已确认这项工作结束 |

项目和任务各自保存状态：完成全部任务不会自动把项目标为完成，修改项目状态也不会批量修改任务。
「最近进展」只记录文字；智能体说“已完成”也不等于正式任务状态变为完成。

### 管理项目与任务文字

通过菜单打开管理窗口，在左侧选择「项目待办」，再用上方项目选择器选中项目。

- 修改项目名称或当前阶段后，点击「保存项目」。
- 修改任务名称后，按回车保存。
- 点击任务状态按钮，可直接调整该条任务状态。
- 点击「刷新」，重新读取最新数据。
- 「项目总览」可按全部、未完成、已完成筛选，也可搜索项目名称；点击项目进入待办。

当前没有日历、截止时间编辑或提醒操作；旧数据中的相关字段保留，但应用不安排提醒。

### 删除前注意所在窗口

- **置顶窗**：点击任务垃圾桶后会要求确认，可选「取消」。
- **管理窗口的项目待办**：任务垃圾桶当前直接删除，没有二次确认，请谨慎点击。
- **删除项目…**：会要求确认，删除项目及其全部任务，包括已归档任务。
- **归档窗口**：删除归档任务会要求确认。

删除不是归档，当前没有撤销删除或回收站。需要保留记录时，优先使用完成与归档。

## 连接智能体

从菜单选择「设置与接入…」，或在管理窗口左下角选择「设置与接入」，打开「智能体连接中心」。
「智能体动态」当前也进入同一接入与审计页面。

### 按四步完成连接

1. **首次授权与权限管理**：优先选择有效的已有身份；没有身份时点「创建新的本机身份」。按需选择创建新项目、创建待办及同时授权当前项目，点击「授权所选范围并记住」。
2. **选择连接方式**：选择 Hermes、Codex、Claude Code、OpenCode 或通用 MCP。点击「预览并配置…」，检查预览后点「确认添加配置」。通用 MCP 用「查看通用配置」复制后导入客户端。
3. **管理当前项目 MCP 权限**：首次授权已保存所选范围。后续可单独更新或撤销当前项目权限；顶部的创建新项目许可单独管理。
4. **验证写入**：若仅获新项目创建许可且尚无项目，先让客户端创建首个项目，再选择该项目。点击「运行 MCP 握手并写入测试动态」，查看是否出现 `accepted`，并回到目标项目核对最近进展。

配置后在对应客户端刷新 MCP 或重新打开会话。客户端未安装时，先按连接中心的官方说明安装；Workdesk 不会自动安装客户端。

可对已授权智能体这样提出要求：

> 请在已授权的“示例项目”中记录进展：初稿已准备好，等待审核。
> 如果该项目允许新增任务，请新增待办“核对发布清单”，并返回写入回执。

这里的项目名只是示例，请替换为你已授权的真实目标。

### 四种提示分别代表什么

| 提示 | 实际含义 |
| --- | --- |
| 已发现 | 找到了客户端可执行文件，还未证明配置或授权成功 |
| 已配置 | Workdesk 写入的配置与本应用记录一致，还未证明客户端已调用 |
| 已绑定／MCP 已授权 | 当前身份获得指定项目的相应权限 |
| accepted | 这一次提交已被接受；结合项目视图核对实际内容 |

本机验证按钮会真实写入一条测试动态，验证的是 Workdesk 自身的 MCP 子进程与存储。
它不证明第三方客户端会话已经成功调用，也不证明 QQ 已接通；仍需在对应客户端实际调用一次并核对回执。

Hermes 历史客户端发现过三工具，本版四工具已有隔离 stdio 验证，当前会话需刷新。Codex 有用户环境接入记录，本次未重测；Claude Code、OpenCode 的真实客户端未验证。
Cursor、Cline、Roo 可尝试通用 MCP，尚未实测。WorkBuddy 可尝试通用 stdio 配置，需在其自身确认信任并重载 MCP；无专用自动发现／配置，真实客户端未验证。界面中的“暂未接入”提示指未提供专用适配。

### 授权范围与撤销

- 当前项目授权只覆盖所选项目，需要其他已有项目时单独授权。创建新项目许可独立保存，默认关闭。
- 新项目自动允许查询与动态，待办权限继承创建时保存的本机选择；改变新项目权限不追溯扩大既有项目权限。项目、绑定、MCP 许可与事件记录在同一事务提交。
- 共享同一个身份的客户端也共享该身份已获授的范围；身份不是每个客户端各自隔离的权限。
- 新增待办任务权限是额外开关。创建项目使用第四个工具 `workdesk_project_create`，须已有本机创建许可；MCP 不提供完成任务、修改状态或自行授权的能力。
- 「撤销当前项目 MCP」取消该项目 MCP 许可；项目映射列表的「撤销」取消绑定，并清除相应 MCP 许可。
- 「撤销创建新项目权限」只取消后续创建许可，既有项目需单独撤销；重放旧创建事件仍检查当前许可。
- 「撤销本应用配置」只撤销客户端配置，项目授权需另外撤销。

添加客户端配置前会备份原文件。若撤销时发现配置已被用户改动，应用会停止，避免覆盖。
遇到同名配置、注释格式或不支持的自定义配置位置时，可使用通用 MCP 预览，请熟悉该客户端配置的人协助合并。
移动 `Workdesk.app` 后，旧配置中的程序位置可能失效，需要重新检查配置。

更多接入与兼容性说明见[多智能体连接中心与 MCP](mcp-connections.md)。

### QQ 管家如何配合

QQ 入口需要你自己的 Hermes 网关、机器人或适配流程明确配置，把获准的进展转交给 Workdesk。
应用没有自带开箱即用的 QQ 机器人，也不会自动读取聊天、自动发送消息或安装定时汇报。

QQ 收到请求、网关运行、Workdesk 接受入站上报是不同环节。要核对本次事件回执与项目进展，不能只看旧的成功记录。
远程聊天中的请求不能替代本机项目绑定、创建许可或环境要求的本地授权。
某些用户环境额外配置的历史记录汇总、定时任务不属于 Workdesk 内置功能。

## 会议收件箱：从转写到正式事项

当前接收**文字转写**，没有应用内录音或音频转写。请先用其他工具转成文字，再粘贴。
会议识别目前只使用 Hermes；连接其他 MCP 客户端不会自动替换会议识别模型。

### 示例流程

1. 在管理窗口选择「会议收件箱」，点「新会议」。先选择会议日期，再粘贴原文。
2. 保留普通口语和上下文，不需要加“待办”标记。例如：

   > 示例项目的初稿已经整理完了，先记录一下进展。接下来要核对发布清单，审核意见还没收到。

3. 原文修改会自动保存，也可点「保存草稿」。首次保存需工作台已有项目。
4. 点「交给智能体识别」，阅读授权说明，再点「授权并识别」。
5. 等待右侧出现建议事项与进度，逐条检查后再选择写入。

授权会把**会议全文、已有项目与任务名称**发送给 Hermes 已配置的模型，可能产生该模型的费用。
本机调用也可能在进程参数中包含会议文字；如内容不宜发送，请取消识别，仅保存草稿。

### 审核右侧建议

每条卡片可以选择是否写入，并在提交前修改：

- 类型：「新增事项」或「记录进度」。
- 目标项目：必须选已有项目，未知或已删除项目会阻止确认。
- 事项内容：调整措辞，保留原意。

每条建议带「依据」原文片段；展开「历史依据」可核对当轮原文、原建议和会议日期。
疑似重复项默认不选，但系统不能识别所有语义改写，仍需人工核对。
负责人和不明确的截止日期不会自动补全；记录进度不会改变正式状态。

会议日期用于理解“今天／明天”等相对表达。已保存会议保留原始日期；旧会议日期未知时不会拿重开日期代替。
重新识别会保留历史证据，不应把新增建议理解为已经入库。

### 确认、失败与重试

核对所选条目后，点「确认并写入所选 N 条」。识别本身只生成草稿，此时才正式提交。
提交使用现有身份及目标项目权限：记录进度需要项目 MCP 授权，新增事项还需要创建待办权限。

- 只有显示「已写入 · accepted」才表示成功；「保存草稿」不等于写入项目。
- 部分失败时，成功条目保留，失败条目继续留在审核区；处理权限或连接问题后重试未成功项。
- 重试沿用原事件以避免重复写入，已提交内容可能锁定；不要靠反复新建相同建议重试。
- 识别最长约 120 秒，可点「取消识别」。取消或识别失败不会自动创建任务，原文仍保留。

### 重开或删除会议

点「打开已存会议」，按日期与文字摘要选择会议，再选「打开」继续审核。
同一菜单内选择「删除…」，确认后删除该会议原文、草稿与识别记录。
**已确认写入项目的任务和进度不随会议删除而删除。**

## 完成任务与归档

任务进入「完成」时记录完成时间。修改已完成任务的标题不会重置计时。
改回其他状态会清除完成时间；下次再次完成，从新时间开始计算。

默认开启「自动归档：完成后 12 小时」。应用运行时为最近到期的已完成任务安排一次性定时器，到期后自动归档并更新界面；启动、数据刷新和系统唤醒时补扫错过的期限。这是按需定时，不是常驻轮询服务。
窗口一直闲置时可能仍显示已到期任务，可在管理窗口的项目待办点「刷新」。
Mac 睡眠或应用退出期间不会持续后台处理；重新启动或刷新后补查已到期任务。

旧版本升级时，若原库没有完成时间字段，已有完成任务从迁移时刻起算 12 小时，不会根据猜测的历史日期立即归档。

在置顶窗「项目任务」旁点「归档 (数量)」，或在底部点「归档设置」：

1. 用「全部」或项目标签筛选已归档任务；数量为全工作台归档总数。
2. 点「恢复为待办」，任务回到原项目、状态变为待办并清除完成计时。
3. 点「删除」并确认，永久删除该归档任务。
4. 点击自动归档开关整行，可开启或关闭；这是全局设置。

关闭自动归档不会恢复已归档任务；再次开启并刷新时，已满 12 小时的完成任务可立即归档。
归档不改变项目状态，任务会从当前任务列表与完成数统计中移出。
归档卡片目前标作“归档”的时间实际取自任务完成时间，按上海时区显示，不是独立记录的归档执行时刻。

## 常见问题

| 遇到的问题 | 处理方法 |
| --- | --- |
| 关掉窗口后找不到应用 | 左键点菜单栏清单图标；需要管理窗口时右键打开菜单 |
| 识别按钮不可点 | 检查是否粘贴了文字，以及连接中心是否有可用的已登记身份 |
| 提示没有 Hermes、接口不支持或模型配置缺失 | 先检查已有 Hermes 安装与模型连接；当前识别要求兼容的单次运行接口，只有 MCP 已连接还不够 |
| 识别超时、输出格式不支持或证据不通过 | 原文保留；检查模型连接后重试，必要时分段识别并人工查重 |
| 配置完成却看不到客户端工具 | 在客户端刷新 MCP 或重开会话，检查应用位置及配置是否变化 |
| rejected／未写入 | 核对身份、目标项目绑定、MCP 许可及新增任务开关，再重试原事件 |
| conflict／版本冲突 | 先刷新读取最新内容，再重新操作；不要直接覆盖另一方的修改 |
| 上报了进展，状态没有变化 | 进展只记录文字；在本机点击状态按钮确认状态 |
| 完成超过 12 小时仍未归档 | 先确认自动归档开关已开启；应用当时未运行时，启动或唤醒后补扫，也可点刷新立即检查 |
| 归档后完成数减少 | 当前统计仅包含未归档任务，可到归档窗口查看历史 |
| QQ 没有同步 | 分别检查 QQ／Hermes 网关、适配流程、本机授权和本次回执，网关在线不代表已送达 |

「设置与接入」底部事件审计展示最近 200 条上报，`accepted` 为已接受、`rejected` 为拒绝、`conflict` 为冲突。
手动操作当前没有统一审计；不要把密钥或其他敏感信息放入进展文字。

## 数据保存与备份

默认数据目录是 `~/Library/Application Support/Workdesk/`，数据库名为 `workdesk.sqlite`。
通过自定义数据目录启动的应用，应备份实际使用的目录。
数据保存在本机；模型识别发送范围以每次授权说明为准，同一 macOS 用户下的其他进程仍可能访问本地文件。

普通用户建议这样备份：

1. 退出 Workdesk，并结束会写入同一工作台的智能体客户端／CLI 任务。
2. 在 Finder 用「前往文件夹…」打开数据目录。
3. 将**整个数据目录**复制到安全的备份位置；保留其中可能存在的 SQLite 辅助文件。
4. 如需恢复连接，另行安全备份本机 Workdesk 身份凭据及客户端配置；凭据是私密文件，不要放入仓库或聊天。
5. 恢复时先停止所有写入，再恢复完整目录；保留原目录副本以便回退。

**不要在应用运行时只复制 `workdesk.sqlite`**：数据库使用 WAL，最新修改可能仍在辅助文件中。
需要在线备份时，请由熟悉 SQLite 的操作者使用其 backup 功能取得一致快照。
归档仍保留数据，删除则需要依靠已有备份恢复；当前没有应用内一键备份或自动云同步。
