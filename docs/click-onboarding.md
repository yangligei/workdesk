# 点击接入智能体

打开 Workdesk 菜单 →「设置与接入…」→「智能体连接中心」。完整操作见[用户指南](user-guide.md#连接智能体)，交给智能体的独立说明见[接入操作指南](agent-integration-guide.md)。

1. **首次授权与权限管理**：选择凭据可用的已有身份；没有身份时点「创建新的本机身份」。程序选择未占用名称并保存私钥，不显示内容，不重建已有身份或轮换密钥。
2. 按需勾选「允许创建新项目」（默认关闭）、「允许创建待办」，已有项目时选择是否「同时授权当前项目」，点击「授权所选范围并记住」。空工作台可仅授权创建新项目，再让智能体创建首个项目；不需要用户执行管理命令。身份登记、客户端发现和配置都不等于授权。
3. **选择连接方式**：选择 Hermes、Codex、Claude Code、OpenCode 或通用 MCP。预览目标配置后点击「确认添加配置」；通用 MCP 复制配置并在客户端导入。WorkBuddy 按通用 stdio 方式尝试，需在 WorkBuddy 自身完成信任确认并重载 MCP；没有专用自动发现／配置适配，未验证其真实客户端。
4. **授予当前项目 MCP 权限**：首次授权已保存所选范围，无需重复授权；后续在此单独更新或撤销当前项目权限。客户端刷新 MCP／重新打开会话后，应发现四工具：查询项目、记录进度、创建待办和创建项目。
5. **验证真实 MCP 写入**：已有已授权项目时点「运行 MCP 握手并写入测试动态」，核对本次 `accepted` 和项目「最近进展」。只有新项目创建许可、尚无项目时，先让客户端调用 `workdesk_project_create`，再查询／选择新项目验证。

新项目的项目记录、别名绑定、MCP 许可与事件回执记录在同一数据库事务提交。自动允许查询与动态，待办权限继承创建时保存的本机选择；后续调整创建范围不追溯修改既有项目。创建别名必须未占用，不能覆盖映射。

同一身份的客户端共享权限。顶部「撤销创建新项目权限」与单项目 MCP 撤销独立；撤销创建许可不会取消已有项目授权，撤销项目绑定会清除相应 MCP 许可。撤销客户端配置也不会撤销权限。幂等重试仍检查当前权限，撤销后不能靠旧事件 ID 取得成功回执。

## 状态含义与限制

- 「已发现」表示找到可执行文件；「已配置」表示配置与本应用写入记录一致；绑定与 MCP 授权仍是独立状态。
- 本机验证按钮验证 Workdesk 自己的 stdio 子进程、签名与存储，不证明第三方会话已调用，更不证明 QQ 收发。需在目标客户端实际调用并核对本次回执。
- UI 可能仍显示 WorkBuddy「暂未接入」的保守提示：没有专用适配，通用尝试不能称为已验证支持。兼容性以[支持矩阵](mcp-connections.md)为准。
- 不自动同步所有对话；智能体须主动调用。MCP 没有完成任务、改状态或自行授权工具。
- 「高级 · Hermes 网关与原签名协议」保留按需检查与旧签名动态测试。网关运行不代表 Workdesk 写入或 QQ 投递成功，不读取聊天或发送 QQ 消息。
- 凭据不在默认位置会显示限制，不猜测或搬动密钥；身份失效应选择有效身份并重新导出配置。

## 隔离与验证边界

`WORKDESK_DATA_DIR` 指定隔离目录时，创建身份也使用该目录下的 `credentials`。现有 `CoreChecks` 覆盖身份复用、无隐式授权、四工具握手、项目创建事务、待办继承、回执、撤销与项目隔离；构建和运行步骤见[连接说明](mcp-connections.md)。本次文档同步未重新构建、启动应用或改动真实授权。
