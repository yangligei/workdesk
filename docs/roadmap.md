# 开发计划

> 当前实现说明（2026-11-05）：下文保留早期设计／计划，未实现条目不构成功能承诺。当前项目与任务由授权智能体创建，状态由本机独立确认；连接中心保存首次范围，创建项目默认关闭、待办单独授权，MCP 提供四工具。用户入口见[用户指南](user-guide.md)，精确能力与验证边界见[接入指南](agent-integration-guide.md)。QQ 与音频转写仍需后续验证／实现。


1. 原生 UI 和存储：可编译 app、手动项目/任务、菜单栏/置顶窗；测空闲成本。
2. 事件接入：CLI、收件箱、去重、恢复、来源映射；适配一个实际智能体。
3. QQ：先验证现有渠道，实测查询和录入；远程文件操作遵守本地授权。
4. 会议：先文字生成草稿，再接转写；在线上传须明确配置授权；重任务按需运行。
5. 按使用反馈增加汇总、提醒、周报与更多适配器；每阶段重新测资源。

当前：第一阶段手动管理 MVP 已实现并完成 Release 编译，核心检查覆盖空名称、参数绑定、持久化 CRUD、冲突、级联删除、外键约束。XCTest 在仅安装 Command Line Tools 的环境受阻，提供 `swift run CoreChecks` 作为可执行验证。

本轮已补项目/阶段及任务标题编辑、原子文件事件与 CLI、来源映射/去重/版本冲突/事件审计、目录通知刷新、会议文字证据草稿与幂等确认。下一步：可视交互验收、来源身份与过滤查询、实际智能体和 QQ 适配、音频转写，以及标准数据量性能测量。真实 app 启动及 live inbox 已隔离验证，不等于可视验收。
