# 流程调整

日历、截止编辑和提醒已撤回。旧项目的 deadline/timezone/reminders 字段保持不变，重新打开不会清除数据；应用不再安排提醒。

项目与任务由获授权智能体创建，界面保留编辑、状态及删除。首次由本机用户在连接中心保存权限：创建新项目默认关闭，待办单独授权，可同时授权当前项目；空工作台可只授权创建项目。四个 MCP 工具分别用于创建项目、查询授权项目、记录进度与创建待办；智能体不能自行授权或完成任务。新项目自动绑定，动态许可及待办继承在同一事务保存。会议识别只产生建议，用户审核确认后使用现有身份和目标项目 MCP 权限入库。

操作见[点击接入](click-onboarding.md)、[智能体指南](agent-integration-guide.md)及[旧签名协议参考](event-protocol.md)。
